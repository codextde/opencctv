Hilfe

Antworten auf die häufigsten Fragen. Nicht dabei? Eröffne ein Issue auf GitHub oder schreib an kontakt@codext.de.

Wie installiere ich den Server?

Am schnellsten mit Docker:

docker run -d --name opencctv --restart unless-stopped --network host -v opencctv:/data ghcr.io/codextde/opencctv:latest

Ohne Docker unter Linux oder macOS curl -fsSL https://opencctv.codext.de/install.sh | sh ausführen, unter Windows in der PowerShell irm https://opencctv.codext.de/install.ps1 | iex. Dann http://<server-ip>:8080 öffnen und das Admin-Konto anlegen. Weitere Wege auf der Startseite.

Die App erreicht meinen Server nicht.
  • Prüfe, ob dein Handy im selben Netz wie der Server ist oder über dein Gateway bzw. VPN verbunden ist.
  • Öffne http://<server-ip>:8080 im Browser des Handys. Klappt das auch nicht, blockiert eine Firewall auf dem Server Port 8080.
  • Erlaube auf dem iPhone „Lokales Netzwerk“ für OpenCCTV unter Einstellungen > Datenschutz & Sicherheit > Lokales Netzwerk.
  • Am zuverlässigsten ist das Koppeln per QR-Code: In der Weboberfläche Benutzer & Geräte öffnen und den Code mit der App scannen.
Wie füge ich eine Tapo-Kamera hinzu?
  1. In der Tapo-App die Kamera öffnen, auf das Zahnrad tippen, dann Erweiterte Einstellungen > Kamerakonto, und Benutzername und Passwort anlegen. Das ist nicht deine TP-Link-ID.
  2. In OpenCCTV eine Kamera hinzufügen, TP-Link Tapo wählen und IP-Adresse sowie dieses Konto eintragen.
  3. Optional: dein TP-Link-Cloud-Passwort eintragen, um Gegensprechen zu aktivieren.

Weder SD-Karte noch Tapo-Care-Abo sind nötig. Schwenkbare Modelle (C200, C210, C500 und ähnliche) werden per ONVIF gesteuert.

Wie füge ich UniFi-Protect-Kameras hinzu?

Nutze den UniFi-Protect-Import in der Weboberfläche: IP deiner Konsole (UDM, UNVR oder Cloud Key) und einen lokalen Protect-Benutzer eintragen. OpenCCTV aktiviert RTSP an den Kameras und fügt sie hinzu. Protect läuft parallel weiter. Am besten funktioniert ein lokaler Benutzer, nicht dein Ubiquiti-Cloud-Konto.

Meine Kamera steht nicht in der Liste. Geht sie trotzdem?

Wahrscheinlich, wenn sie RTSP oder ONVIF anbietet. Wähle „ONVIF-Kamera“, um den Stream automatisch zu finden, oder „Andere“ und füge die RTSP-URL aus dem Handbuch ein. Kameras, die nur senden können, schicken RTMP oder RTSP an den Server; OpenCCTV zeigt die Ziel-URL nach dem Speichern an.

Reine Cloud-Kameras wie Ring, Arlo, Blink oder Nest haben keinen lokalen Stream und funktionieren nicht. Bei eufy muss RTSP unter Speicher > NAS (RTSP) aktiviert sein, Wyze-Kameras brauchen die offizielle RTSP-Firmware.

Push-Mitteilungen kommen nicht an.
  • Erlaube Mitteilungen für OpenCCTV in den Systemeinstellungen und schalte sie in der App ein.
  • Prüfe, ob Bewegungserkennung und Mitteilungen für die Kamera auf dem Server aktiv sind.
  • Nach einer Mitteilung wartet die Kamera die auf dem Server eingestellte Pause ab, bevor sie die nächste sendet.
  • Der Server braucht Internetzugang, um Mitteilungen über den Push-Dienst von Expo zu senden.
Wie sehe ich meine Kameras von unterwegs?

Entweder ein zweites OpenCCTV als Gateway auf einem VPS oder in Coolify betreiben und den Server zu Hause unter Einstellungen > Fernzugriff damit verknüpfen, oder ein VPN wie Tailscale oder WireGuard nutzen und die VPN-Adresse des Servers in der App eintragen. Beides ohne Portfreigabe.

Wie lade ich nach Google Drive, S3 oder auf mein NAS hoch?

In der Weboberfläche unter Speicher ein Ziel hinzufügen. Bei Google Drive meldest du dich einmal mit deinem Google-Konto an, bei S3, SMB, SFTP, FTP und WebDAV trägst du Adresse und Zugangsdaten ein. Jedes Ziel hat eine eigene Aufbewahrungsdauer in Tagen. Vor dem Speichern „Testen“ nutzen.

Wie aktualisiere ich den Server?

Docker: docker pull ghcr.io/codextde/opencctv:latest, dann den Container entfernen und mit demselben Befehl neu starten. Deine Daten bleiben im Volume.

Installer: den Installationsbefehl erneut ausführen. Er ersetzt das Programm und startet den Server neu.

Ich habe das Admin-Passwort vergessen.

Auf dem Server opencctv reset-password <benutzername> ausführen. Der Befehl gibt ein neues Zufallspasswort aus; mit einem zweiten Argument legst du selbst eins fest. Danach den Server neu starten, falls er lief.

Wie entferne ich meine Daten?

In der App den Server aus der Serverliste entfernen; die App löscht die gespeicherte Adresse und den Token. Auf dem Server das Datenverzeichnis löschen (das Docker-Volume, ~/.opencctv oder %APPDATA%\OpenCCTV) und die Aufnahmen in deinen Speicherzielen. Wir haben keine Kopie deiner Daten.

Ist OpenCCTV kostenlos?

Ja. Server und Apps sind Open Source unter der MIT-Lizenz, ohne Werbung, Abo oder In-App-Käufe.
